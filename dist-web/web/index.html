只有你自己时不会有声音

服务器的规则是「混别人的声音、排除自己」，所以房间里只有你一个人时是安静的。要听到声音，让另一个人（或用桌面客户端 jt-cli）连上同一台服务器。

网页版延迟比桌面端高

WebSocket 走 TCP + 浏览器音频缓冲，单向大约 60–120 ms，适合听排练、对节奏参考，不适合严格意义上的 <20 ms 合奏。追求低延迟请用桌面客户端。

带宽

不压缩 16-bit PCM：48 kHz × 16 bit ≈ 0.75 Mbps 上行、同样下行。网速够用但别用蜂窝数据。

需要 HTTPS 与授权

麦克风要求安全上下文（本站已是 HTTPS）。Safari 对 AudioWorklet 支持较早，推荐 Chrome / Edge；iOS 上建议耳机并注意自动增益。
